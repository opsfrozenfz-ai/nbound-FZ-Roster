ผูกติดกับ Google Sheets โดยตรงแล้ว (Native Mode)

หน้าเว็บนี้กำลังรันผูกติดกับหลังบ้าน Google Apps Script ของชีตนี้โดยตรง ทุกคนที่เปิดใช้งานผ่าน Google Sites จะซิงค์ข้อมูลอัตโนมัติโดยไม่ต้องตั้งค่า URL

ยังไม่ได้เชื่อมต่อ Google Sheets

วางลิงก์ Web App URL จาก Google Apps Script ด้านล่างเพื่อเริ่มซิงค์หลังบ้าน

แนะนำสำหรับ Google Sites: กดแท็บ "🌐 วิธีอัปขึ้น Google Sites" เพื่อผูกไฟล์หน้าเว็บและ Code.gs เข้าด้วยกันโดยไม่ต้องกรอก URL ซ้ำบนแต่ละเครื่อง

ประวัติการซิงค์ล่าสุด

ยังไม่มีประวัติการซิงค์

📌 โค้ดหลังบ้าน Code.gs (รองรับทั้งผูกติด Google Sites และ API ภายนอก)

  1. เปิด Google Sheets ที่ใช้เก็บฐานข้อมูล (ตั้งชื่อเช่น Inbound FZ Roster DB)
  2. ไปที่เมนูด้านบน ส่วนขยาย (Extensions) → Apps Script
  3. วางโค้ดด้านล่างลงในไฟล์ Code.gs แล้วกดบันทึก (Ctrl+S)
  4. กดปุ่ม + (เพิ่มไฟล์) → HTML ตั้งชื่อไฟล์ว่า index แล้วนำโค้ดหน้าเว็บ HTML นี้ทั้งหมดไปวาง (เพื่อให้หน้าเว็บผูกติดกับชีตนี้ 100%)
  5. กด Deploy → New deployment → Web app เลือก Me และ Anyone แล้วนำ URL ไปฝังบน Google Sites ได้เลย!

✨ ตั้งค่า XFrameOptionsMode.ALLOWALL ให้พร้อมฝังใน sites.google.com แล้ว และสร้าง 4 ชีตอัตโนมัติ (Employees, Attendance, DailySummary, SyncMeta)

ไฟล์หลังบ้าน: Code.gs (พร้อม HtmlService + google.script.run + LockService)
วิธีที่ 1 (แนะนำที่สุด)

ผูกหน้าเว็บติดกับ Google Sheets แล้วฝังลง sites.google.com

วิธีนี้ ไม่มีปัญหา CORS และ ไม่ต้องตั้งค่า URL ในเครื่องพนักงาน ทุกคนที่เข้าเว็บ Google Sites จะซิงค์เข้า Google Sheets เดียวกันทันที:

  1. ในโปรเจกต์ Apps Script ของ Google Sheet ให้มี 2 ไฟล์คู่กัน คือ Code.gs (คัดลอกจากแท็บที่ 2) และ index.html (โค้ดไฟล์เว็บแอปนี้ทั้งหมด)
  2. กด การทำให้ใช้งานได้ (Deploy) → รายการใหม่ (New deployment) → เว็บแอป (Web app) เลือก ดำเนินการในฐานะ: ฉัน (Me) และ ผู้ที่มีสิทธิ์เข้าถึง: ทุกคน (Anyone)
  3. คัดลอก URL เว็บแอป ที่ได้ (ลงท้ายด้วย /exec)
  4. เปิด Google Sites (sites.google.com) → เมนูขวาเลือก แทรก (Insert) → ฝัง (Embed) → ตาม URL (By URL) → วาง URL เว็บแอป → เลือก ทั้งหน้า (Whole page) → ขยายกรอบให้เต็มหน้าจอแล้วกด เผยแพร่ (Publish)!

📦 โค้ด <iframe> สำเร็จรูปสำหรับวางใน Google Sites (แบบ "ฝังโค้ด")

ใส่ URL เว็บแอปที่ Deploy แล้วเพื่อสร้างโค้ดฝังแบบเต็มความกว้างอัตโนมัติ

💡 วิธีที่ 2: ฝังโค้ด HTML โดยตรง (Embed Code) บน Google Sites หรือเว็บโฮสติ้งอื่น

หากต้องการวางไฟล์ HTML นี้เดี่ยวๆ บนเว็บอื่นโดยไม่ใส่เป็น index.html ใน Apps Script ให้แก้ค่า BAKED_CONFIG.GAS_WEBAPP_URL ที่บรรทัดบนสุดของแท็ก <script> เป็น URL เว็บแอปของคุณ แอปจะเชื่อมต่อชีตให้อัตโนมัติทุกเครื่องเช่นกัน
